🐛 SVG Engine — Bug Demonstration Page

Each section shows a known issue. Expected vs actual behavior noted.

Bug #1: Gradient strokes silently dropped

Gradient stroke renders invisible on polylines/paths
ACTUAL: The right stroked elements are invisible (no stroke rendered)
EXPECTED: All shapes should show a visible gradient stroke

Bug #2: Radial gradient on polygon fills bounding rectangle

Polygon with radial gradient overflows outside the shape
ACTUAL: The gradient fill spills outside the triangle into the bounding rectangle area
EXPECTED: Gradient should be confined to the triangle shape

Bug #3: Pattern fill on polygon fills bounding rectangle

Polygon with pattern fills the bounding rect, not the shape
ACTUAL: The pattern fills the outer bounding rectangle, overflowing outside the triangle
EXPECTED: Pattern should be clipped to the triangle shape

Bug #4: userSpaceOnUse gradient has wrong origin on polygon

Gradient coordinates use bbox origin instead of viewport origin
ACTUAL: The same gradient on two different triangles shows the gradient band at DIFFERENT relative positions (shifted by the triangle's bbox offset)
EXPECTED: userSpaceOnUse should use absolute (viewport) coordinates, so both triangles should show the same gradient bands at the same absolute positions
