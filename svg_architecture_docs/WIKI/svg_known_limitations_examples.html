SVG Known Limitations — Test Cases

Examples that fail under Servo's current serialize-as-image approach. Open in Chrome to see expected behavior, then compare with Servo.

Case 1

CSS doesn't cross the SVG boundary

Expected: Text is green because fill:green on the parent div cascades into the SVG.
Servo: Text is black. The serialization severs CSS inheritance from parent document.
Expected: Text is red — currentColor resolves to parent's color value.
Servo: Text is black. currentColor can't resolve across the serialization boundary.
Case 2

Web fonts can't be used

Expected: Top text renders in Saira Stencil web font.
Servo: Falls back to default serif. Web font @import is never fetched by usvg.

Case 4

Animations don't work

Expected: Circle pulses r=30→r=50, cycles blue→orange→blue.
Servo: Static. No animation tick occurs in the image-cache pipeline.
Expected: Gear rotates continuously via animateTransform.
Servo: Static. No animation evaluation.
Case 5

<foreignObject> doesn't work

Expected: A styled HTML card with purple border appears inside the SVG.
Servo: Empty — foreignObject is stripped by usvg during parsing.
Case 6

Scripting inside SVG doesn't work

Expected: Text reads "Script executed successfully!" and circle is orange.
Servo: Text stays "Waiting for script..." and circle is teal. Script never runs.
Expected: Six colored bars with value labels generated by JavaScript.
Servo: Empty — script-driven DOM creation never executes.
