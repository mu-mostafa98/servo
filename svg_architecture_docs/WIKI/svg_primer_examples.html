Chapter 2 — Coordinate System Model

The most important SVG concept. viewBox, preserveAspectRatio, nested viewports, and transforms.

2.1 viewBox Mapping

§2 viewBox

No viewBox — raw 200×200

<svg width="200" height="200"> — user unit = 1 CSS pixel

viewBox="0 0 100 100" — 2× scale

<svg viewBox="0 0 100 100"> — 100×100 mapped to 200×200 → 2× scale

2.2 preserveAspectRatio

§2 preserveAspectRatio

xMidYMid meet (default)

Scale to fit: 100×100 scales by min(2,1)=1×, centered

xMinYMin slice

Scale to fill: 100×100 scales by max(2,1)=2×, cropped

xMinYMin meet

Align top-left, scale to fit

none (stretch)

Stretch to fill — aspect ratio NOT preserved, circle becomes ellipse

2.3 Nested Viewports (<svg> inside <svg>)

§2 Nested Viewports
Each nested <svg> creates an independent viewport with its own viewBox scaling. Dashed circle shows outer SVG center.

2.4 The transform Attribute

§2 Transform
Left-to-right: translate, rotate(45), scale(1.5), skewX(20), matrix(). Transforms are right-to-left in composition order.

Chapter 3 — Paint Servers

Fill and stroke are not just colors — they can reference gradients, patterns, and other paint servers via url(#id).

3.1 Solid Color vs. Gradient Fill

§3 Paint Servers

Solid fill="red"

Simple — no resolution needed

Gradient fill="url(#g)"

Engine must resolve url(#g3_1) to a gradient definition

3.2 Gradient Coordinate Modes

§3 objectBoundingBox vs. userSpaceOnUse

objectBoundingBox (default)

Gradient fits each element's bounding box. Different positions, different gradient.

userSpaceOnUse

Gradient uses absolute coordinates. Both elements see the same gradient region.

3.3 Paint Server Reference Chain

§3 The Reference Problem
Paint servers can reference other paint servers. Your engine must resolve chains recursively.

Chapter 4 — Rendering Tree vs. DOM Tree

Not all DOM elements become rendering tree nodes. Painter's algorithm: elements draw in DOM order.

4.1 Painter's Algorithm — DOM Order

§4 Draw Order

First-to-last DOM order

Blue at (80,80) — drawn first. Orange at (120,120) — drawn on top, covers intersection.

Reversed DOM order

Orange at (120,120) drawn first. Blue at (80,80) drawn on top — different intersection.

4.2 display:none vs. visibility:hidden

§4 Rendering Tree
display:none → removed from rendering tree (not rendered, not in layout). visibility:hidden → in rendering tree but not painted (still affects bounding boxes).

Chapter 5 — The <use> Element

SVG's element cloning mechanism. Creates a shadow tree copy with attribute overrides.

5.1 Basic <use>

§5 Element Reuse
<use> clones the referenced element and positions it at the given x,y. The clone is in a shadow tree — it behaves like a copy but the styling can be overridden.

5.2 Attribute Overriding on <use>

§5 Attribute Override
The <use> element's attributes override the cloned element's matching attributes. fill="green" on <use> replaces fill="blue" from the <defs> definition. transform applies to the entire cloned subtree.

Chapter 8 — Clipping, Masking, and Filters

Offscreen render surfaces: clipPath, mask, and filter pipelines.

8.1 clipPath

§8 Clip Path

No clip

Clipped to circle

Complex clip path

clip-path="url(#id)" clips the element's rendering to the path defined in <clipPath>. The clip shape uses the same coordinate system.

8.2 Mask

§8 Mask

Luminance mask

Mask uses luminance: white = opaque, black = transparent, gray = semi-transparent

Mask with shapes

Black in mask = hidden, white = visible. Multiple shapes create complex masks.

8.3 Filter Effects

§8 Filter

feGaussianBlur

feDropShadow

feColorMatrix (grayscale)

Filter chain (blur + color)

Filters are a pipeline of primitives. Input → feGaussianBlur → feColorMatrix → feMerge → Output. Each primitive processes a pixel buffer. SourceGraphic is the element's own rendering.

Chapter 9 — SMIL Animation

SVG's built-in animation system. Time-varying attribute overrides that drive re-render.

9.1 <animate> — Scalar Attributes

§9 Animation
<animate attributeName="cx" values="50;250;50" dur="4s"> — interpolates cx from 50 to 250 and back over 4 seconds. Multiple animations on one element (cx + r). begin="1s" staggers start time.

9.2 <animateTransform>

§9 Transform Animation
animateTransform overrides the element's transform attribute. type="rotate" rotates around a center point. When applied to <g>, all children move together. Chained animations: group translates while child rotates.

9.3 <set> and Color Animation

§9 set + Color
<animate> can interpolate colors (fill), numbers (rx, width), and opacity. <set> (not shown here) instantly sets a value without interpolation. keyTimes controls exact timing — values go 1→1→0→0 to create a blink pattern.
