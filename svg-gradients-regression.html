Linear Gradient: objectBoundingBox

Gradient coordinates use percentages relative to the shape bounds. The vector runs from right to left so the blue stop appears on the left edge.

Linear Gradient: userSpaceOnUse

Gradient coordinates use absolute user space lengths.

Radial Gradient: objectBoundingBox

Radial gradient with percent-based center, radius, and focus point.

Radial Gradient: userSpaceOnUse

Radial gradient with absolute user space coordinates and explicit focus.
