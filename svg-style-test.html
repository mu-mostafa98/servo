SVG Style Properties — Test Suite

Each test shows expected vs actual behavior. If a test looks wrong, that property is not working.

1. opacity

Three circles at opacity 1.0, 0.5, 0.2 (left→right)
Expected: Middle circle is half transparent, right is very faint

2. stop-opacity (gradient stops)

Linear gradient: red(0.3) → blue — left side should be semi-transparent
Expected: Left side (red) should be semi-transparent, fading to opaque blue
Radial gradient with stop-opacity 0.4 on middle stop
Expected: Middle ring of radial gradient should be translucent red

3. visibility

Three rects: visible, hidden, visible (hidden should not paint)
Expected: Only red and blue rects visible. Green rect area shows background behind SVG.
visibility:hidden on group — all children hidden
Expected: No rects visible (both hidden by group)

4. display: none

Group with display:none — children should NOT render
Expected: Only blue rect visible. Red and green rects completely vanish (no layout space).

5. vector-effect: non-scaling-stroke

Top line: non-scaling-stroke (should stay 2px). Bottom line: normal (scales with transform)
Expected: Red line = 3px thick. Blue line = ~1.8px thick (3 × 0.6). Red line is visibly thicker.

6. fill-opacity & stroke-opacity

Rect: fill-opacity 0.3 + stroke-opacity 0.5
Expected: Faded red fill, semi-transparent blue stroke

7. Combined: group opacity × fill-opacity

Group opacity 0.5 + child fill-opacity 0.5 = 0.25 total
Expected: Very faint red (0.5 × 0.5 = 0.25 alpha times red color)

8. visibility:hidden inside group with opacity

Group opacity 0.6, one child visibility:hidden
Expected: Red and blue dimmed by 0.6 opacity. Green rect not visible.

9. Landscape-like composite (smoke test)

Multi-layer scene using opacity, gradients, visibility
Expected: Scene with translucent sun glow, mountains, river, and one visible cloud

10. clip-path with circle

Rect clipped to a circle — only content inside the circle should show
Expected: Red circle visible. Corners of the rect clipped away outside the circle.
Blue rect clipped to circle with outline showing boundary
Expected: Blue circle with white outline showing exact clip boundary.

11. clip-path with rounded rect

Rect clipped to a rounded rectangle
Expected: Green rect clipped to rounded corners (20px radius).

12. clip-path with ellipse

Elliptical clip with gradient fill
Expected: Red ellipse visible, corners clipped away.

13. clip-path with userSpaceOnUse

Rect clipped using userSpaceOnUse coordinates
Expected: Orange rounded rect visible from (20,10) to (100,70).

14. shape-rendering: crispEdges

Rounded rects: top=crispEdges (sharp), bottom=default (smooth)
Expected: Both rects look similar on screen. Bottom one may have sharper/crisper corner edges.

15. shape-rendering: geometricPrecision (tessellation)

Complex polygon fill: left=geometricPrecision (smooth), right=optimizeSpeed (fast)
Expected: Left polygon has smoothest edges (most triangles). Right polygon may show slightly coarser edges. Middle = default.

16. shape-rendering with gradient

Gradient fills: left=geometricPrecision (smooth), right=optimizeSpeed (faster bands)
Expected: Left is smoothest gradient (many thin bands). Right shows coarser banding. Middle = default.

17. Pattern: checkerboard

Checkerboard pattern — 20x20 tile with alternating red/white squares
Expected: Checkerboard pattern with red and white alternating 10x10 squares, repeating across the full rect.

18. Pattern: stripes

Diagonal stripe pattern
Expected: Blue rect with white diagonal stripes repeating every 30px.

19. Pattern: with pattern offset

Pattern shifted by x=10,y=10 offset, each tile is 40x40 with a circle
Expected: Yellow rect with red circles every 40px, shifted 10px down and right.

20. Polygon with gradient fill

Triangle polygon filled with linear gradient
Expected: Triangle filled with red→blue horizontal gradient.

21. Polygon with pattern fill

Hexagon filled with checkerboard pattern
Expected: Hexagon filled with repeating checkerboard pattern.

22. Polyline with gradient fill

Irregular polyline filled with vertical gradient
Expected: Irregular shape filled with green→yellow vertical gradient.

23. Mask with circle

Rect masked by a circle - only content inside the circle should show
Expected: Red circle visible. Corners of the rect clipped away outside the circle mask.

24. Mask with rounded rect

Rect masked by a rounded rectangle mask
Expected: Blue rect visible only through the rounded rectangle.

25. Multiple shapes in mask

Two circles in a mask - both clipping regions apply
Expected: Two green circles visible.

26. Filter: Gaussian blur

Red rect with Gaussian blur (stdDeviation=3)
Expected: Red rectangle with blurred (soft) edges. The blur should be visible at the corners.

27. Filter: Drop shadow

Blue circle with drop shadow (dx=4, dy=4, blur=3)
Expected: Blue circle with a soft gray shadow offset 4px right and 4px down.

28. Viewport overflow clip (default hidden)

Default: content outside SVG viewport is clipped. Circle at x=10,y=10 should be cut off on left/top.
Expected: Only bottom-right quarter of the circle visible (clipped to viewport).
Overflow visible: content outside SVG viewport should show. Circle at x=10,y=10 visible in full.
Expected: Full circle visible extending beyond the left/top edge of the SVG viewport.
Overflow visible on right/bottom: rect starting at x=80,y=80 in a 100x100 viewport.
Expected: Blue rect extends beyond bottom and right edges of the SVG viewport.

29. visibility attribute in pattern shapes (pattern attr path)

Pattern with visibility:hidden on a child shape — hidden circle should not render
Expected: Dark gray rect with NO circles (they are hidden). Empty pattern tile.
Pattern with visibility:visible on a child — circle shows normally
Expected: Dark gray rect with lime green circles every 40px.
