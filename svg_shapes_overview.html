SVG Shapes: Unification Concept

All SVG shapes are specializations of <rect>.

Part 1: <rect> — styling

Rectangles with various fill, stroke, and opacity combinations.

← fill, stroke, rx/ry rounded corners, stroke-width, stroke-opacity

Part 2: Ellipse via <rect>

Ramping rx/ry on a rect creates rounder shapes, converging to an ellipse.

← rect rx/ry: 0 → 10 → 20 → 28 → 30 (beyond half-size, it's visually an ellipse)

← wide rect (80×50): rx/ry capped at min(w,h)/2 = 25, then rx=80 clipped to 25 → pure ellipse

← tall rect (50×80): same concept, ry clipping at 40 → pure ellipse

Part 3: <ellipse> tag

Native ellipse elements — the reference implementation vs the rect-based approximation above.

Part 4: Circle via <ellipse> tag

An ellipse with rx == ry is a circle. Ramping rx toward ry shows the transition.

← ellipse ry: 10 → 20 → 30 → 38 → 40 (=rx) → pure circle

Part 5: <circle> tag

Native circle elements.

Part 6: Line via <rect>

Angled lines approximated with rotated rectangles (using CSS transform). A thin long rotated rect is visually a line.

← rect width=200, height=6 rotated 0° → 15° → 30° → 45° → 60°

← varying stroke width via rect height: 4 → 8 → 12 → 16 → 20

Part 7: <line> tag

Native line elements — direct representation of the same angled lines from Part 6.

← angled lines with different colors and stroke widths
