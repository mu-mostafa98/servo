<g> Inheritance Test Suite

1. Basic inheritance — fill set on <g>

1a. Inherit fill from parent <g>

<g fill="red"> → <rect> should be red

1b. Inherit fill from <g> with different shape types

<g fill="steelblue"> → all children steelblue

1c. Inherit stroke from <g>

<g stroke="purple" stroke-width="3" fill="none">

1d. Inherit both fill & stroke from <g>

<g fill="coral" stroke="navy" stroke-width="2">

2. Explicit override — child overrides inherited values

2a. Child overrides inherited fill

<g fill="red"> → <rect fill="blue"> should be blue

2b. Child overrides inherited stroke

<g stroke="red" stroke-width="3" fill="none"> → child with own stroke

2c. Partial override — child overrides only fill-opacity

<g fill="red"> → <rect fill-opacity="0.3"> red at 30% opacity

2d. Partial override — child overrides only fill-rule for <polygon>

<g fill="teal"> → polygon with fill-rule="evenodd" (star with hole)

2e. Child fill="none" inside <g fill="red">

<rect fill="none"> should be invisible (no inherited red)

2f. Child stroke="none" inside <g stroke="red" stroke-width="3">

<rect stroke="none"> should have no stroke

3. Inline style attribute

3a. Inline style overrides inherited fill

<g fill="red"> → <rect style="fill:green">

3b. Inline style with opacity preserves inherited fill

<g fill="red"> → <rect style="opacity:0.4"> (should preserve inherited red)

3c. Inline style with both fill and opacity

<g fill="red"> → <rect style="fill:purple;opacity:0.6">

4. Nested <g> — deep inheritance

4a. Two levels of <g> inheritance

<g fill="coral"> → <g stroke="teal"> → rect inherits both

4b. Three levels — outer fill, middle stroke, inner override

<g fill="gold"> → <g stroke="purple" stroke-width="2"> → rect overrides fill

5. Transform + inheritance

5a. <g> with transform and inherited fill

<g fill="seagreen" transform="translate(10,10)">

5b. Transform + override

<g fill="teal" transform="..."> → rect overrides to "tomato"

6. Mixed <g> + <defs> (gradients)

6a. Gradient reference inside <g>

<g fill="url(#g1)"> → children use gradient

7a. Standalone rect with explicit fill

7b. Standalone rect without fill (default black)

8a. Empty <g> (no children)

8b. <g> with only text (not rendered — expected, text is future work)
